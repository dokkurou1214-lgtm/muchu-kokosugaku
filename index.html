LESSON / 数学Ⅰ

平方完成で頂点を求める

中学で学んだ展開を、逆向きに使う技術です。

STEP 01 / 中学数学からつなぐ

まず (x + 3)² を展開する

(x + 3)² = x² + 6x + 9

逆に見ると、x² + 6x = (x + 3)² − 9 です。最後に「+9した分を−9する」ことで、式の値を変えずに平方の形にできます。

コツ：x の係数の 半分 をカッコに入れて、最後に2乗分を調整する。
STEP 02 / 実際に変形する

y = x² − 6x + 5 を変える

① x の係数 −6 の半分は −3② x² − 6x = (x − 3)² − 9③ y = (x − 3)² − 9 + 5④ y = (x − 3)² − 4

頂点は (3, −4)。カッコ内が 0 になる x が3で、そのときの y は−4です。

STEP 03 / x²の係数が1ではないとき

先に x² の係数でくくる

y = 2x² − 8x + 3= 2(x² − 4x) + 3= 2[(x − 2)² − 4] + 3= 2(x − 2)² − 5

頂点は (2, −5)。係数が負なら放物線は下向きですが、頂点の読み取り方は同じです。

理解できたら、問題で確かめる

まずは基本問題5問から取り組みましょう。

STEP 01 / 平方完成から考える

上に開く・下に開くで決まる

y = (x − 2)² − 1

(x − 2)² は0以上なので、x = 2で最小値 −1 をとります。上に開く放物線には、x の範囲が指定されない場合、最大値はありません。

y = −(x + 1)² + 3

一方、−(x + 1)² は0以下なので、x = −1で最大値 3 をとります。この場合、最小値はありません。

STEP 02 / 定義域がある場合

両端と頂点を比較する

y = (x − 1)² + 2 （−1 ≦ x ≦ 3）
左端 x = −1：y = 6右端 x = 3：y = 6頂点 x = 1：y = 2（定義域内）最大値 6、最小値 2

最大値6をとる x は −1と3の2つ。端点の値が同じになることもあります。

STEP 03 / 頂点が範囲外のとき

頂点を候補に入れない

y = (x − 4)² + 1 （−1 ≦ x ≦ 2）
頂点 x = 4 は範囲外左端 x = −1：y = 26右端 x = 2：y = 5最大値 26、最小値 5

頂点が範囲外にある場合は、その点の値を最大値・最小値の候補に含めません。

手順：①平方完成 → ②頂点が定義域内か確認 → ③左右の端点と必要なら頂点を比較。

最大・最小の基本を練習

まずは定義域なしの基本5問から。

STEP 01 / グラフと方程式のつながり

x軸との共有点は「y = 0」で考える

y = x² − 4x + 3

x軸上では y = 0 です。つまり x² − 4x + 3 = 0 の実数解が、グラフとx軸の共有点のx座標になります。

x² − 4x + 3 = (x − 1)(x − 3)x = 1、3 の2つの実数解したがって共有点は2個です。
STEP 02 / 判別式を使う

D = b² − 4ac の符号を見る

ax² + bx + c = 0 （a ≠ 0）
D = b² − 4acD > 0：共有点は2個（異なる2点で交わる）D = 0：共有点は1個（接する）D < 0：共有点は0個（交わらない）

平方根の中が0より大きいか、ちょうど0か、負になるかで実数解の個数が決まります。

STEP 03 / 実際に計算する

同じ二次関数でも定数項で変わる

y = x² − 4x + 3：D = 16 − 12 = 4 → 2個y = x² − 4x + 4：D = 16 − 16 = 0 → 1個y = x² − 4x + 5：D = 16 − 20 = −4 → 0個

係数 a・b・c を正しく読み取り、bが負でも b² は0以上であることに注意しましょう。

STEP 04 / 文字mの条件

Dをmの式にして、不等式を解く

y = x² − 4x + m + 1
D = (−4)² − 4(m + 1) = 12 − 4m2個：D > 0 → m < 31個：D = 0 → m = 30個：D < 0 → m > 3
不等式を負の数で割ると、不等号の向きが逆になる点に注意。
